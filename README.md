# SAMI KHAN — The Glass Archive ⛩️

> A cinematic, scroll-driven 3D architectural portfolio and interactive monograph blending Japanese aesthetics, custom WebGL/Three.js shaders, and spatial audio soundscapes.

---

## ✨ Features

- **Three.js & WebGL Visuals**: Procedural crystal geometries, optical dispersion, refraction, and chromatic aberration.
- **Scroll-Driven Narrative**: Smooth Lenis scrolling synchronized with GSAP animations.
- **Authentic Japanese Aesthetic**: Handcrafted calligraphy brush strokes (*fude-kiri*), sumi ink typography, and traditional Hanko seals.
- **Interactive Specimen Lab**: Interactive 3D artifact inspector with multi-mode shader controls.
- **Spatial Audio & Soundscapes**: Ambient atmospheric soundscapes and tactile feedback.

---

## 🚀 Tech Stack

- **Framework**: React 18
- **3D Graphics**: Three.js
- **Animations**: GSAP (GreenSock)
- **Smooth Scroll**: Lenis
- **Build Tool**: Vite 5

---

## 🛠️ Local Development

```bash

npm run dev

# Build for production
npm run build

# Preview production build
```
